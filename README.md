# Mini_Project
# Impact of Remote Work on Mental Health

## Power BI Data Analytics Project

### Project Overview

This project focuses on analysing the relationship between remote work patterns, employee productivity, workplace conditions and mental health indicators.

The objective is to explore how factors such as working hours, work location, work-life balance, stress levels, social isolation, sleep quality and organisational support are represented across the workforce.

Using Microsoft Excel, Power Query and Power BI, the project transforms raw data into an interactive analytical report that helps users explore employee well-being patterns and workplace trends.

---

## 1. Project Objectives

The key objectives of this project are:

- Analyse employee distribution across different work locations, industries and regions.
- Examine stress levels and reported mental health conditions.
- Understand the relationship between working hours and work-life balance.
- Explore social isolation, sleep quality and physical activity patterns.
- Compare employee experiences across gender categories.
- Analyse access to mental health resources.
- Identify factors statistically associated with high stress levels.
- Present meaningful information through interactive dashboards and visual reports.

## 2. Dataset Description

**Dataset:** Remote Work and Mental Health Dataset  
**Source:** Kaggle  
**Approximate records:** 5,000  
**Number of columns:** 20

The dataset contains employee-related information, including:

- Employee ID
- Age and Gender
- Job Role and Industry
- Years of Experience
- Work Location
- Hours Worked per Week
- Number of Virtual Meetings per Week
- Work-Life Balance Rating
- Stress Level
- Mental Health Condition
- Access to Mental Health Resources
- Productivity Change
- Social Isolation Rating
- Satisfaction with Remote Work
- Company Support for Remote Work
- Physical Activity
- Sleep Quality
- Region

## 4. Data Cleaning and Preparation

Data cleaning was performed using Microsoft Excel Power Query.

The following operations were carried out:

1. Trimmed unnecessary leading and trailing spaces.
2. Cleaned text columns to remove unwanted characters.
3. Standardised text formatting using Capitalize Each Word.
4. Assigned appropriate data types to columns.
5. Checked for missing and empty values.
6. Checked for data errors.
7. Identified and removed exact duplicate records by comparing all columns.
8. Validated numerical ranges and categorical values.

The cleaned dataset was loaded into Power BI for further analysis.

## 5. Data Analysis Using DAX

DAX was used to create calculated measures and calculated columns for analytical purposes.

### A. Measures Created

1. Total Employees
2. Average Age
3. Average Weekly Hours
4. Average Work-Life Balance
5. Average Social Isolation

### B. Calculated Columns Created

1. Age Group
2. Experience Group
3. Working Hours Category
4. Work-Life Balance Category
5. Social Isolation Category

These calculations support employee segmentation, KPI reporting and comparative analysis.

## 6. Power BI Dashboard Development

The report consists of four interactive pages.

### Page 1 – KPI Overview

Provides a high-level summary of the dataset through five KPI cards:

- Total Employees
- Average Age
- Average Weekly Hours
- Average Work-Life Balance
- Average Social Isolation

### Page 2 – Overview Dashboard

Provides an overall view of employee working patterns and well-being indicators.

Visualisations include:

- Employee Distribution by Work Location and Region
- Stress Level Distribution
- Mental Health Condition Distribution
- Productivity Change by Work Location
- Employee Distribution by Sleep Quality
- Mental Health Conditions by Work Location

Interactive slicers:

- Region
- Industry
- Work Location
- Mental Health Condition
- Access to Mental Health Resources

### Page 3 – Gender-Based Analysis

Explores differences and patterns across gender categories.

Visualisations include:

- Employee Distribution by Gender
- Stress Level Distribution by Gender
- Mental Health Conditions by Gender
- Average Work-Life Balance by Gender
- Average Weekly Working Hours by Gender
- Productivity Change by Gender

### Page 4 – Regional Insights

Provides detailed employee information and geographical analysis.

Key components:

- Employee Details and Work Patterns Table
- Regional Distribution Map
- Regional Comparison of Work-Life Balance Matrix
- Employee Distribution Decomposition Tree

Additional features include:

- Conditional formatting
- Female and Male employee bookmarks
- Regional Bookmarks
- Page Level Filter on Table
- Report Level Filter by Work Location and Mental Health Condition
- Region-based drill-through functionality

## 8. Key Areas of Analysis

The report explores the following analytical areas:

**Employee Distribution:** Workforce distribution across regions, industries and work locations.

**Mental Health and Stress:** Distribution of reported mental health conditions and stress levels.

**Work-Life Balance:** Comparison of work-life balance ratings across employee groups and working patterns.

**Productivity:** Analysis of reported productivity changes across work locations and gender categories.

**Employee Well-being:** Exploration of sleep quality, physical activity and social isolation.

**Organisational Support:** Examination of access to mental health resources and company support for remote work.

**Gender-Based Analysis:** Comparative exploration of employee experiences across gender categories.

## 10. Project Limitations

This analysis is based on the available dataset and its recorded employee attributes.

The findings represent patterns and statistical associations within the dataset. They should not be interpreted as proof of causal relationships between remote work and mental health outcomes.

## 11. Conclusion

This project demonstrates an end-to-end data analytics workflow, starting from data cleaning and preparation through DAX-based analysis to interactive Power BI dashboard development.

The final report provides an accessible way to explore employee work patterns, productivity, workplace conditions and mental health indicators across different employee groups.

It also demonstrates practical knowledge of data transformation, analytical calculations, interactive reporting and advanced Power BI features.
