# Mini_Project
# Data Analysis with Excel and Power BI
# Impact of Remote Work on Mental Health
## Data Cleaning

## Tool Used
- Microsoft Excel
- Excel Power Query

## Dataset Overview
- **Source:** Kaggle
- **Records:** Approximately 5,000
- **Columns:** 20
- **Domain:** Remote Work and Mental Health

## Data Cleaning and Preparation

The following operations were performed using Excel Power Query:

1. **Trim:** Removed unwanted leading and trailing spaces from text columns.
2. **Clean:** Removed unwanted non-printable characters.
3. **Capitalization:** Standardised text values using Capitalize Each Word.
4. **Data Type Correction:** Assigned appropriate data types to numerical and categorical columns.
5. **Missing Value Inspection:** Checked all columns for null and empty values. No missing values were identified.
6. **Error Inspection:** Examined column quality and confirmed that no data errors were present.
7. **Duplicate Handling:** Removed exact duplicate records by selecting all columns, preserving records with matching Employee IDs but differing information.
8. **Data Validation:** Inspected numerical ranges and categorical values for consistency.
